# Resilient Token Validation Service — Python

This repository contains a 60-minute coding and engineering-judgment exercise for a Senior Engineering Manager.

Start with [CANDIDATE_INSTRUCTIONS.md](CANDIDATE_INSTRUCTIONS.md). The starter code uses only the Python 3 standard library.

## Quick start

macOS/Linux:

```bash
./run-tests.sh
```

Windows PowerShell:

```powershell
./run-tests.ps1
```

The starter implementation is intentionally incomplete and unsafe for production. Finding and explaining problems is part of the exercise.
